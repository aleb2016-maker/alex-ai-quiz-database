# Review RAG

Questa cartella serve per controllare le domande generate dal RAG prima di qualsiasi importazione nei database ufficiali.

I file JSON generati qui sono locali e vengono ignorati da Git.

Regola:

- non importare mai automaticamente in data/
- controllare fonte RAG
- controllare risposta corretta
- controllare i tre distrattori forti
- controllare spiegazione e lingua
- approvare manualmente prima dell'importazione futura
