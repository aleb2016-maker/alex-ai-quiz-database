# START HERE — Crea il tuo quiz Android, Web o Demo

Questo progetto serve a creare quiz riutilizzabili, non solo a mostrare una demo.

## 1. Crea un nuovo progetto

Dalla pagina GitHub del repository premi:

Use this template

In questo modo ottieni una copia del progetto nel tuo account.

## 2. Genera un pacchetto quiz

Nel tuo repository vai su:

Actions → Crea pacchetto quiz → Run workflow

Poi scegli:

- platform: android, web oppure demo
- subject: materia del test
- level: livello
- number: numero domande

Alla fine scarica il pacchetto dagli Artifacts.

## 3. Usa il pacchetto

Per Android:
copia database_quiz.json dentro app/src/main/assets/

Per Web:
usa index.html e database_quiz.json

## 4. Scopo del progetto

Il progetto serve per creare quiz su AI, Informatica, Matematica, Inglese, Logica, Scienze, Fisica, Chimica, Biologia e altre materie future.
