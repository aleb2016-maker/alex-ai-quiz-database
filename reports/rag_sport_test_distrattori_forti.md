# Miglioria test sport

- Migliorati i distrattori del test sport.
- Rimosse risposte assurde o troppo facili da eliminare.
- Ogni domanda ora usa 1 risposta corretta + 3 distrattori più vicini al tema.
- Il test resta interattivo: risposta corretta nascosta fino al feedback.
- Le domande duplicate per blocchi ripetuti vengono ridotte.
