# OCR locale server

Creato server OCR locale separato.

File principali:

- `scripts/rag_ocr_server_locale.py`
- `demo-rag/test-ocr-locale.html`

Funzioni:

- TXT
- PDF con testo selezionabile
- PDF immagine tramite conversione pagine
- immagini JPG/PNG/WEBP
- modalità tabella/scheda
- modalità fumetto/balloon
- riparatore testo tabella sport
- analisi qualità OCR

Motivo: Tesseract nel browser era troppo debole per tabelle e fumetti.
