Motore RAG locale

Carica TXT, PDF o Markdown e genera materiale utile

Trasforma un documento in riassunto, tabelle, card di ripasso, quiz interattivo e file scaricabili. La demo lavora nel browser; il pacchetto include anche lo script Python locale.

Seleziona un file e premi il pulsante.

Uso nel pacchetto scaricato

Metti un file nella cartella documenti/ e lancia:

python3 scripts/rag_motore_documenti_completo.py documenti/tuo_file.pdf --titolo "Titolo documento"

Il comando termina da solo e crea gli output dentro output_generati/.
