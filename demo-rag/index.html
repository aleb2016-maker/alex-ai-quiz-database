Motore RAG Documenti

Carica o incolla un documento e genera subito una bozza di riassunto, quiz, card formative, tabella operativa o parole chiave. Questa pagina è una demo browser leggera. Il pacchetto scaricabile contiene invece la base riutilizzabile per pipeline più complete.

1. Inserisci il documento Puoi incollare testo oppure caricare TXT, MD, CSV o PDF con testo selezionabile.
2. Scegli l’output Di base è selezionato solo il riassunto. Gli altri output li scegli tu.
3. Genera e scarica Premi un solo pulsante principale: “Genera output”. Poi puoi scaricare il risultato.
