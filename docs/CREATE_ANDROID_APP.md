# Creare un'app Android quiz

## File principale

Il file generato si chiama:

database_quiz.json

## Dove metterlo

In Android Studio copialo dentro:

app/src/main/assets/database_quiz.json

Se la cartella assets non esiste, creala manualmente.

## Flusso consigliato

1. Leggi il JSON dagli assets.
2. Filtra le domande per categoria e livello.
3. Mescola le domande.
4. Mostra 10 o 20 domande.
5. Controlla la risposta corretta.
6. Mostra la spiegazione.
7. Mostra il risultato finale.

## Vantaggio

Puoi cambiare materia sostituendo solo il database JSON, senza rifare tutta l'app.
