# Motore Web Quiz

Questo pacchetto web contiene:

- database_quiz.json
- quiz-engine.js
- 1_APRI_QUIZ.html
- README_LEGGIMI.html

## Cosa fa quiz-engine.js

Il motore web:

- filtra le domande per categoria
- filtra le domande per livello
- mescola le domande
- crea test da 10, 20 o tutte le domande
- controlla la risposta corretta
- calcola il punteggio
- valida la qualità minima delle domande

## Uso base

Apri:

1_APRI_QUIZ.html

Il test parte direttamente nel browser.
